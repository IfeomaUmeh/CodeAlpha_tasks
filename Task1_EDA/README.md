# CodeAlpha Data Analytics Internship: Superstore EDA

Exploratory data analysis of the Superstore sales dataset (9,994 orders, 2014 to 2017), completed for the CodeAlpha Data Analytics Internship.

## Tools
Python, pandas, Matplotlib, Google Colab

## Files
- `CodeAlpha_SuperstoreEDA.ipynb`: the full analysis notebook
- `Sample - Superstore.csv`: the dataset

## What I did
1. Loaded and inspected the data (21 columns, no missing values, no duplicates)
2. Converted the order and ship dates to date format
3. Answered four questions with tables and charts

## Key findings
- **Category:** Technology earns the most profit (145,454.95). Furniture has high sales but only a 2.5% margin.
- **Region:** West is the strongest region. Central has the weakest margin (7.9%).
- **Discounts:** Orders discounted above 20% lose money on average.
- **Sales trend:** Sales grew 51% from 2014 to 2017 and peak between September and December.
